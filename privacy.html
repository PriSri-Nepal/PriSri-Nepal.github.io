Privacy Policy

Sri Story Uploader is a personal tool used only by its owner to upload videos to the owner's own YouTube channel through the YouTube Data API.

What data it uses

The tool uses Google sign-in permission only to upload videos, set thumbnails and set video details on the owner's own channel. It does not collect, store, sell or share any data about other people or YouTube viewers.

Storage

The access permission is stored as an encrypted secret in the owner's private GitHub repository and is used only to upload the channel's videos.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube API Services Terms of Service.
